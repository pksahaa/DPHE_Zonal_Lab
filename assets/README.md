# DPHE LIMS — Report Logos (GitHub Assets)

Place your laboratory report header logos in this folder:

1. `logo_left.png` — Left header logo (e.g., National Emblem / Bangladesh Govt Seal)
2. `logo_right.png` — Right header logo (e.g., DPHE Emblem)

These logos are referenced automatically by the Custom Report Generator on generated certificates.

### How to customize in Settings:
Go to **Settings ▸ Lab Identity / Letterhead** in the LIMS web application. You can:
- Specify the relative GitHub path (e.g., `assets/logo_left.png`, `assets/logo_right.png`)
- Specify a raw GitHub image URL (e.g., `https://raw.githubusercontent.com/username/repo/main/assets/logo_left.png`)
- Or upload a custom image file directly from your local computer.
